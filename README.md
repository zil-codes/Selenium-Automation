🚀 SauceDemo Automation Using Python & Selenium

This project automates a full purchase flow on SauceDemo using Python, Selenium WebDriver, and Chrome Incognito Mode.
The script performs a complete end-to-end test, including login, adding an item to the cart, checkout, and logout.

📌 Features Covered

Opens Chrome in Incognito Mode

Logs into SauceDemo with standard credentials

Adds a product to the shopping cart

Navigates to checkout and enters user information

Completes the purchase order

Logs out and closes the browser
